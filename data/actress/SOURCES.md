# 女优别名数据说明

本目录下的 `alias.json` 是本仓库自有、自行维护的「女优标准名 → 全部别名（含简中/繁中/旧艺名/假名变体）」映射数据，
用于搜索与展示时的别名归一化。

## 数据结构

- 顶层为扁平 JSON 对象：`{ "标准名(canonical)": [别名数组], ... }`。
- 别名数组可包含：中文译名、汉字/假名拼写变体、旧艺名、常用昵称。

## 处理要点

归一化逻辑见 `scripts/alias_norm.py`（独立实现）。要点：

- **整组 cluster 并入**：精选女优 c 的搜索别名 = c 自身作为 canonical key 的别名列表，
  ∪「把 c 列为别名」的每个 canonical 的整组别名。例如 楓カレン 在表里仅作 田中レモン
  名下的一个别名，归一化时会把 田中レモン / 田中檸檬 等整组并入，不会整组丢弃。
- **冲突告警、不自动合并**：同名若同时落入 ≥2 个精选女优 cluster，才视为「真实误并」，
  仅向 stderr 告警、不改写数据，避免污染扩散。
- **已确认同一人**：`楓カレン = 田中レモン`（中文 枫花恋）。两名为同一人，请勿拆分。
