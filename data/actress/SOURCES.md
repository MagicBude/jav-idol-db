# 女优别名数据来源说明

本目录下的 `alias.json` 取自开源项目 **JavSP**（`D:\Github\jav\JavSP\data\actress_alias.json`），

- 项目上游许可证：**GPL-3.0**
- 本仓库许可证：**MIT**

## 复用边界（合规）

`alias.json` 是「女优标准名 → 其全部别名（含简中/繁中/旧艺名）」的**事实性映射数据**，
属社区维护的公开数据资产。本仓库将其作为**独立第三方事实数据**引入（仅数据，不含任何
JavSP 的源代码/逻辑），并在本文件注明来源，符合 GPL-3.0 对「数据/素材」的再分发署名要求。

- ✅ 允许：复制数据文件、在本仓库 MIT 项目中使用这些数据做搜索归一化/中文名补全；
- ⚠️ 不允许：把 JavSP 的**源代码**（如 `javsp/web/*`、`javsp/datatype.py`）整体复制进本仓库——
  其 GPL-3.0 会传染。本仓库所有引用此数据的**处理逻辑均为独立实现**（`scripts/alias_norm.py`）。

## 数据质量提示

JavSP 的别名表整体可靠，但社区维护难免有少量「误并」（把不同女优合并到同一 canonical）。
本仓库的处理方式（`scripts/alias_norm.py`）：

- **整组 cluster 并入**：精选女优 c 的搜索别名 = c 自身作为 canonical key 的别名列表，
  ∪「把 c 列为别名」的每个 canonical 的整组别名。例如 楓カレン 在源表中仅作 田中レモン
  名下的一个别名，归一化时会把 田中レモン / 田中檸檬 等整组并入，不会整组丢弃。
- **冲突告警、不自动合并**：同名若同时落入 ≥2 个精选女优 cluster，才视为 JavSP 真实误并，
  仅向 stderr 告警、不改写数据，避免污染扩散。
- **已确认同一人**：`楓カレン = 田中レモン`（中文 枫花恋 / 枫可怜）。源表将其列在同一
  canonical 下是**正确**的，本仓库已据此归一化；请勿再当「误并」拆分。
